Welcome Craftknights!


This is the official download site for the English translation patch of Summon Night: Swordcraft Story ~Hajimari no Ishi~! After over a decade of development, we are proud to release a full translation!



What has been translated?


We've tried to make this patch as complete as possible. Everything has been translated by people who know Japanese and English. Then proofread several times by native English speakers. Here's a list of things we've translated!

  • All Dialogue
  • All Menu UI
  • All Images With Text
  • Character Names
  • Location Names
  • Item Names and Descriptions
  • Bestiary Names and Descriptions
  • Minigame Rules
  • Credits
  • Pretty much all Japanese text in the game



Incomplete / Uncovered / Altered things


Sometimes, due to hardware limitations or other outstanding factors, there were some things we could not accomplish.

  • Voices lines are still in Japanese
  • We have not tested on physical hardware
  • Some lines may not be centered when they should be
  • Swordcraft Story 3 (The Japanese title does not contain a 3. But this name has stuck for a decade now so we're not changing it.)


Where can I download the patch?


The translation patch can be downloaded from the Download page.

You will need to apply the patch to your legally obtained copy of Summon Night: Swordcraft Story ~Hajimari no Ishi~.



What if I find a bug?


We have worked very hard to make sure we haven't introduced any gameplay bugs. We have also proofread the script several times to fix any translation/grammar errors. However, we are still human. It's very possible we have missed some things.

If you find a bug - gameplay, transaltion, or otherwise - we would appreciate it if you left a bug report on the project's Github page.
