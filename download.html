Changelog



Report a bug


We have worked very hard to make sure we haven't introduced any gameplay bugs. We have also proofread the script several times to fix any translation/grammar errors. However, we are still human. It's very possible we have missed some things.

If you find a bug - gameplay, translation, or otherwise - we would appreciate it if you left a bug report on the project's Github page.


Credits


Many people have worked on this project over the years. Most of the original members are no longer active. The project started out on GBATemp over a decade ago but moved over to Discord after many years. All of the current members in the Sworcraft Story 3 Translation Team are currently on Discord.
